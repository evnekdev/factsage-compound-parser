# Security policy

## Supported versions

The current `0.1.x` development line is the supported version. No older release line is currently maintained.

## Reporting a problem

For malformed-input, parser-crash, file-corruption, or dependency vulnerabilities, report the issue privately through GitHub's private vulnerability reporting or security-advisory mechanism when available for this repository. If private reporting is unavailable, open a minimal public issue without sensitive data and request private follow-up.

Do not attach proprietary CDB files, records, names, formulae, comments, coefficients, or encoded excerpts to public reports. Synthetic or hand-constructed byte arrays are preferred.

Please include the crate version or commit, Rust toolchain, operating system, a concise reproduction, and whether the input is synthetic. Redact private database content from logs and stack traces.
